Q: Why is online disabled?

A: The way DRRR does online is fundamentally incompatible with Emscripten. Because of how web apps work (sandboxing), they simply don't allow data to be sent straight to random IPs over UDP.

Q: I'm getting a file not found error when trying to start the game?

A: Hit clear all data, refresh, then hit start. This will erase your saves, but you shouldn't have any if the game won't start.

Q: Can you add Legacy GL support?

A: No.

Q: Why does this run so badly?

A: Mainly browser overhead + a lack of thread usage. Not much I can do here, sorry.

Q: Part of the game is cropped out!

A: That's not a question. Anyway, enable fullscreen in the game options.
